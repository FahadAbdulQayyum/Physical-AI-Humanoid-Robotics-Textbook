# Data Model

This document outlines the data models for the entities defined in the `spec.md`.

## Entity: Documentation Page

*   **Description**: Represents a single page of documentation.
*   **Attributes**:
    *   `title` (string): The title of the documentation page.
    *   `content` (string): The Markdown content of the page.
    *   `url` (string): The URL slug for the page.
*   **Relationships**: None.
