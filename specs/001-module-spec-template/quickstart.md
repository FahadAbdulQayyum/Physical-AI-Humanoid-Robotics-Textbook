# Quickstart Guide

This guide provides instructions on how to build and run the Docusaurus site locally.

## Prerequisites

*   Node.js (version 18.x or higher)
*   npm or yarn

## Installation

1.  Clone the repository.
2.  Install the dependencies:

    ```bash
    npm install
    ```

    or

    ```bash
    yarn install
    ```

## Running the site

1.  To start the local development server, run:

    ```bash
    npm start
    ```

    or

    ```bash
    yarn start
    ```

2.  Open your web browser and navigate to `http://localhost:3000`.

The site will automatically reload if you make changes to the source files.
